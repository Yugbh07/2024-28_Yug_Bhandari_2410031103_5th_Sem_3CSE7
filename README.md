## 📌 About the Internship

The internship focused on building a practical foundation in Machine Learning and Deep Learning using **TensorFlow**, with applications in computer vision, image classification, object detection, and product image search for mobile applications.

The program followed a structured, week-wise curriculum consisting of conceptual learning, hands-on labs, assessments, and practical activities. The internship concluded with a final credential validation and completion of the AI-ML virtual internship program.

**Organization:** EduSkills Academy — runs the AICTE–EduSkills Virtual Internship Program under the **AICTE National Internship Portal**, supported by **Google for Developers**.

## 🎯 Objectives

- Build convolutional neural networks (CNNs) using TensorFlow.
- Understand practical Machine Learning and Deep Learning workflows.
- Work with image classification models.
- Understand and implement object-detection workflows.
- Explore TensorFlow Lite for on-device machine learning.
- Train and work with custom object-detection models.
- Build product image search functionality using object detection.
- Detect objects in static images and live camera feeds.
- Understand backend integration for ML-based applications.
